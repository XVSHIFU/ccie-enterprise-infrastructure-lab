# 三路由器运行配置基线

来源：2026-10-25 用户提供的三台 show running-config 完整文本。
整理方式：去掉终端提示符、输出标题、时间注释、空行及感叹号分隔符；保留全部配置命令与顺序。这是实际运行配置的规范化归档，不是逐字终端日志，也不是 startup-config 采集。用于查阅比较，不应整段粘贴当作配置脚本。

- R1：OSPF area 0，Loopback0 10.255.0.1/32。
- R2：OSPF 与 AS 65001 边界，仅将 10.255.0.3/32 从 BGP 重分发到 OSPF；通过 network 发布自身与 R1 的 Loopback。
- R3：AS 65002，Loopback0 10.255.0.3/32。
- 三台未见遗留静态路由；R3 无 Loopback99 与临时 network。
- R2 查询 10.255.99.3 返回 Subnet not in table，临时路由撤销完成。
- 运行配置中未见密码、密钥等需要脱敏的字段。
- 本基线为单路径基础练习，不代表最终混合广域网或高可用方案完成。
